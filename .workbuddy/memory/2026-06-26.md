# 2026-06-26 工作日志

## P0 问题修复

### P0-1: 95#累计涨跌 NaN bug
- 原因：`FALLBACK_DATA.meta.base95` 在 data.json 中不存在
- 修复：改为使用 `prices[0].p95`（第一轮数据）作为基准

### P0-2: ECharts 暗色模式支持
- 新增 `getChartTheme()` 辅助函数，检测 `prefers-color-scheme: dark`
- `renderMainChart()` 和 `renderBarChart()` 的 axisLabel/axisLine/splitLine/dataZoom 等全部使用主题色
- 0#柴油线色在暗色下从 #374151 切换为 #94a3b8
- 图表实例存储为 `_mainChartInst` / `_barChartInst`，主题变化时 dispose 并重绘
- resize handler 添加 150ms debounce

### P0-3: 时间线动态生成
- 新增 `generateTimeline(prices, city)` 函数
- 分组逻辑：连续同类型（up/down）调价自动合并为一个时间段
- 自动计算：日期范围、累计变动、峰值标记、首降/首涨转折标记
- 所有数值（价格、涨跌幅、省钱金额）从 data 动态计算
- 移除硬编码 HTML，替换为 `<div id="timelineContainer">` 容器

### P0-4: PWA 图标 + Service Worker
- `scripts/generate_icons.py`：Pillow 生成油滴图标（192/512/64 px PNG）
- `favicon.png` 替代原来的 `favicon.jpg`
- `manifest.json`：补充 icons 数组
- `sw.js`：cache-first 策略，缓存核心资源（index.html/data.json/echarts CDN）
- `index.html`：注册 SW，更新 favicon 引用
